# ldd.ly

Official website of Libyan Data Diwan (ديوان البيانات الليبي) — currently an "under construction" page.
Arabic, right-to-left. The home page is an unveiling: a rendered scene of the brand arch under a satin veil among dunes, with live text over it. One look on every device.

Static site served by GitHub Pages (`CNAME` → www.ldd.ly). No build step.

| File | Purpose |
| --- | --- |
| `index.html` | Under-construction page |
| `404.html` | Not-found page |
| `styles.css` | Shared styles, brand tokens and glass surfaces |
| `main.js` | Footer year and the pointer-follow light on glass panels |
| `scene-wide-*.webp`, `scene-tall-*.webp` | Rendered backdrop: landscape (desktop) and portrait (phones), several widths |
| `favicon.svg`, `*.png`, `og-image.jpg` | Icons and social share image |
